04 / LIVE MULTIPLAYER

AI movement control

SHORT INPUT PULSES

Ask the selected model to move the foreground Quake III client. The gateway accepts only movement, strafe, jump, crouch, attack and bounded mouse-look actions. Keep the Quake III window focused.

Verify access and load a model before using live controls.

Each model action is a 40–250 ms input pulse. The bridge releases keys after every pulse; repeat control requests for continued movement. Windows, Linux X11/Wayland, and macOS are supported. Wayland requires an explicit opt-in because focus cannot be verified generically.

Set Q3_ASSET_ROOT on the gateway to the folder containing your .pk3 files, then scan.
Scan assets and configure an AI provider to request a catalog-validated selection.
